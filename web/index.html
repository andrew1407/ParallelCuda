ParallelCuda Labs

The ParallelCuda labs, running in your browser. CUDA doesn't run in a browser, so each kernel is ported to a WebGPU compute shader with the same grid, blocks, shared memory, barriers and atomics, and checked and timed against a JavaScript CPU reference.

Timings are measured in your browser: GPU times include submitting the work and waiting for it, and they vary between runs and devices. WGSL has no 64-bit floats, so the labs' double math runs in f32 on the GPU, while the CPU reference keeps f64.
